# 定时任务与调度 · 简介

> 定时任务、调度与无人值守自动化

## 能做什么

- 定时执行脚本
- 开机 / 登录自启
- 失败重试
- 日志留痕
- 通知推送

## 适合的项目

- **日报 / 周报推送**：周期任务
- **定时备份**：数据安全
- **数据同步**：周期搬运

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Windows 计划任务（内置）、cron、APScheduler、n8n（可选）
- 注意：⚠️ 笔记本注意：建计划任务务必加「电池供电也启动、不停止、错过后补启」

## 快速开始

```bash
schtasks /Create /TN "MyJob" /TR "node job.mjs" /SC DAILY /ST 12:00
schtasks /Run /TN "MyJob"
schtasks /Query /TN "MyJob"
```
