# 定时任务与调度 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| Windows | 计划任务 / schtasks | 系统级调度 |
| Linux | cron / systemd timer | 经典调度 |
| Python | APScheduler | 进程内调度 |
| 编排 | n8n | 可视化工作流 |
| 通知 | 邮件 / Webhook | 结果送达 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **调度表达式**：cron 与计划任务触发
- **笔记本坑**：电池、休眠、错过补启
- **可靠性**：重试、超时、并发控制
- **可观测**：执行日志与告警

## 学习路径

1. 先建一个简单的定时任务
2. 再处理可靠性与通知
3. 最后统一多任务的入口
