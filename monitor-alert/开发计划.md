# 监控与告警脚本 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 采集指标

- **目标**：看得见
- **产出**：指标输出脚本

- [ ] 读 CPU / 内存
- [ ] 打印 / 落盘
- [ ] 周期采样

## 阶段二 · 阈值告警

- **目标**：会通知
- **产出**：超限通知

- [ ] 设阈值
- [ ] 接通知渠道
- [ ] 防重复告警

## 阶段三 · 多维度

- **目标**：更全面
- **产出**：多指标监控

- [ ] 端口探测
- [ ] 接口探活
- [ ] 日志异常

## 阶段四 · 自愈看板

- **目标**：可交付
- **产出**：自愈 + 看板

- [ ] 自动重启
- [ ] 恢复通知
- [ ] 可视化看板

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 采集指标 | 指标输出脚本 |
| 阶段二 · 阈值告警 | 超限通知 |
| 阶段三 · 多维度 | 多指标监控 |
| 阶段四 · 自愈看板 | 自愈 + 看板 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
