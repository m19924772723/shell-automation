# 监控与告警脚本 · 简介

> 系统 / 服务监控与告警脚本

## 能做什么

- 资源监控（CPU / 内存 / 磁盘）
- 进程与服务守护
- 端口与接口探测
- 日志异常告警
- 推送通知

## 适合的项目

- **本机巡检**：资源与健康
- **服务可用性**：接口探活
- **定时告警**：异常通知

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：PowerShell / Bash / Python（psutil 需装）、Uptime Kuma（可选）、Webhook
- 注意：本机可跑轻量监控；大规模监控建议用专业平台

## 快速开始

```bash
pip install psutil
python monitor.py --interval 60
# 超阈值时发通知
```
