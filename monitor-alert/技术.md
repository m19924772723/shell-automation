# 监控与告警脚本 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 采集 | psutil / WMI | 系统指标 |
| 探测 | HTTP / TCP 探测 | 服务可用 |
| 判据 | 阈值与基线 | 触发条件 |
| 告警 | 邮件 / Webhook | 通知渠道 |
| 看板 | Uptime Kuma | 可视化 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **指标基线**：正常范围与波动
- **阈值分级**：警告与严重
- **静默窗口**：避免告警风暴
- **自愈**：自动重启与恢复

## 学习路径

1. 先采集一个指标
2. 再加阈值与通知
3. 最后做自愈与看板
