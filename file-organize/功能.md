# 文件批量整理与备份 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 重命名

- **规则化**：前缀 / 序号 / 日期
- **批量替换**：名称清理
- **预览**：执行前确认

## 归类

- **按类型**：后缀分目录
- **按日期**：拍摄 / 修改时间
- **按大小**：分组处理

## 去重

- **哈希判重**：MD5 / SHA
- **相似图片**：感知哈希
- **保留策略**：留最新 / 最清晰

## 备份

- **增量同步**：只搬变化
- **定时执行**：计划任务
- **压缩归档**：节省空间

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
