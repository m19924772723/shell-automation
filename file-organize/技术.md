# 文件批量整理与备份 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 脚本 | PowerShell / Bash / Python | 按习惯选 |
| 同步 | robocopy / rsync | 增量镜像 |
| 去重 | 哈希比对 | 内容级判重 |
| 压缩 | 7-Zip / tar | 归档打包 |
| 元数据 | ExifTool | 照片信息 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **先预览后执行**：dry-run 机制
- **回收站优先**：可恢复删除
- **哈希去重**：同内容不同名
- **增量同步**：只搬变化

## 学习路径

1. 先做目录遍历与统计
2. 再做归类与去重
3. 最后做定时同步
