# 文件批量整理与备份 · 简介

> 文件批量整理、重命名与备份

## 能做什么

- 批量重命名与归类
- 重复文件查找
- 压缩与解压归档
- 定时同步备份
- 按 EXIF / 日期整理

## 适合的项目

- **下载目录整理**：按类型归类
- **照片归档**：按日期分目录
- **项目备份**：增量同步

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：PowerShell / Bash / Python、robocopy / rsync、7-Zip、ExifTool（可选）
- 注意：⚠️ 整理个人目录务必先预览再执行，优先走回收站

## 快速开始

```bash
robocopy D:\src D:\dst /E /MIR
python organize.py --dry-run   # 先预览
python organize.py --apply
```
