# 环境初始化与一键部署 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 包管理 | winget / scoop / choco | Windows 三选 |
| 容器 | Docker | 环境隔离 |
| 配置 | dotfiles + chezmoi | 配置同步 |
| 编排 | Ansible / 脚本 | 批量执行 |
| 校验 | 体检脚本 | 一致性检查 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **包管理器**：winget / scoop / choco 差异
- **幂等安装**：重复执行不出错
- **配置即代码**：dotfiles 管理
- **体检校验**：验证环境完整

## 学习路径

1. 先写一个装软件的脚本
2. 再抽成声明式清单
3. 最后加配置同步与校验
