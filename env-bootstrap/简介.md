# 环境初始化与一键部署 · 简介

> 开发环境一键初始化与批量部署

## 能做什么

- 批量安装软件
- 配置同步
- 环境变量管理
- 一键部署
- 版本锁定

## 适合的项目

- **新机初始化**：快速就绪
- **团队环境统一**：减少差异
- **可复现环境**：配置即代码

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：winget / scoop / Chocolatey（需装）、Docker、dotfiles
- 注意：声明式清单 + 幂等安装，重装系统后一键恢复

## 快速开始

```bash
winget install --id Git.Git
scoop install nodejs python
# 或用清单脚本批量装
```
