# DevOps 与 CI/CD · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| CI | GitHub Actions | 免搭建 |
| 容器 | Docker / Compose | 环境一致 |
| 编排 | K8s / kubectl | 规模化 |
| 缓存 | actions/cache | 加速构建 |
| 密钥 | Secrets / Vault | 安全管理 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **流水线阶段**：检查 → 构建 → 测试 → 部署
- **Dockerfile**：分层与缓存
- **环境隔离**：dev / staging / prod
- **密钥管理**：不明文入库

## 学习路径

1. 先写一个 Dockerfile
2. 再配一条 CI 流水线
3. 最后做自动部署
