# DevOps 与 CI/CD · 简介

> 持续集成 / 交付流水线与 DevOps 自动化

## 能做什么

- 自动构建与测试
- 镜像打包与推送
- 一键部署
- 多环境编排
- 密钥与配置管理

## 适合的项目

- **项目 CI**：自动测试
- **自动发布**：多平台分发
- **容器化部署**：环境一致

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Docker 29.7.2 + compose、kubectl（已装）、Git、GitHub 账号
- 注意：本机有 Docker 与 kubectl；无云集群时可本地 Docker 演练

## 快速开始

```bash
docker compose up -d
docker compose logs -f
git push   # 触发 CI
```
