# Bash / Git Bash 脚本 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| Shell | Bash 4/5 | 跨平台脚本 |
| 文本 | awk / sed / grep | 文本处理三剑客 |
| JSON | jq | 结构化处理 |
| 检查 | ShellCheck | 静态检查 |
| 调度 | cron / 计划任务 | 定时执行 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **变量与引用**：引号与转义
- **管道与重定向**：组合命令
- **文本处理**：awk / sed 常用写法
- **健壮性**：set -euo pipefail

## 学习路径

1. 先写一个文件批处理脚本
2. 再学文本处理三剑客
3. 最后加错误处理与调度
