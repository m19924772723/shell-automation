# Bash / Git Bash 脚本 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 文件脚本

- **目标**：跑通
- **产出**：一个批处理脚本

- [ ] 遍历目录
- [ ] 条件判断
- [ ] 输出结果

## 阶段二 · 文本处理

- **目标**：会处理
- **产出**：文本清洗脚本

- [ ] grep / sed
- [ ] awk 统计
- [ ] jq 处理 JSON

## 阶段三 · 健壮化

- **目标**：可靠
- **产出**：带错误处理的脚本

- [ ] set -euo
- [ ] 参数解析
- [ ] ShellCheck 通过

## 阶段四 · 自动化

- **目标**：可交付
- **产出**：定时部署脚本

- [ ] 接入调度
- [ ] 日志输出
- [ ] 失败通知

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 文件脚本 | 一个批处理脚本 |
| 阶段二 · 文本处理 | 文本清洗脚本 |
| 阶段三 · 健壮化 | 带错误处理的脚本 |
| 阶段四 · 自动化 | 定时部署脚本 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
