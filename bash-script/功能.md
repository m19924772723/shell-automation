# Bash / Git Bash 脚本 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 文本

- **查找替换**：sed
- **统计提取**：awk
- **过滤匹配**：grep

## 文件

- **批量操作**：遍历处理
- **压缩打包**：tar / zip
- **同步备份**：rsync 思路

## 进程

- **后台运行**：nohup / &
- **进程管理**：ps / kill
- **并发**：xargs -P

## 部署

- **构建脚本**：一键构建
- **环境准备**：依赖安装
- **发布**：打包与上传

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
