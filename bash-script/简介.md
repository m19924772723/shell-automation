# Bash / Git Bash 脚本 · 简介

> 用 Bash / Git Bash 写跨平台自动化脚本

## 能做什么

- 文件批处理与文本处理
- 文本解析与转换
- 进程与任务管理
- 部署与构建脚本
- 日志分析

## 适合的项目

- **开发环境脚本**：构建与部署
- **文本处理**：日志与数据
- **批处理**：文件批量操作

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Git Bash（内置）、awk / sed / grep、jq（需装）、ShellCheck（需装）
- 注意：Windows 下注意路径转换与换行符（CRLF）

## 快速开始

```bash
bash script.sh
chmod +x script.sh && ./script.sh
shellcheck script.sh   # 可选
```
