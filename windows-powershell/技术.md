# Windows PowerShell 运维 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| Shell | PowerShell 5.1 / 7 | 对象管道 |
| 系统 | WMI / CIM | 查询系统信息 |
| 文本 | Select-String / ConvertTo-Json | 处理与导出 |
| 测试 | Pester | 脚本单测 |
| 调度 | 计划任务 | 定时执行 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **对象管道**：不是文本而是对象流
- **CIM 查询**：硬件与服务信息
- **错误处理**：try / catch 与 ErrorAction
- **编码**：中文路径与输出编码

## 学习路径

1. 先写一个系统信息脚本
2. 再做文件批量处理
3. 最后接计划任务定时跑
