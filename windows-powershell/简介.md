# Windows PowerShell 运维 · 简介

> 用 PowerShell 自动化 Windows 系统运维

## 能做什么

- 系统信息采集与巡检
- 批量文件操作
- 注册表 / 服务管理
- 计划任务管理
- 报表输出

## 适合的项目

- **Windows 运维**：巡检与批处理
- **批量处理**：文件与注册表
- **环境治理**：软件与配置

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：PowerShell 5.1（内置）、WMI / CIM、计划任务、Pester（需装）
- 注意：注意执行策略与编码；复杂脚本建议改用 PowerShell 7

## 快速开始

```bash
powershell -NoProfile -Command "Get-ComputerInfo"
powershell -File ./inspect.ps1
# 输出结果到文件
```
