# Windows PowerShell 运维 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 系统

- **信息采集**：硬件与系统
- **服务管理**：启停与状态
- **进程管理**：查找与结束

## 文件

- **批量重命名**：规则化
- **批量移动**：按类型归类
- **内容替换**：多文件替换

## 服务

- **注册表**：读写配置
- **计划任务**：创建与管理
- **环境变量**：读取与设置

## 报表

- **结构化输出**：CSV / JSON
- **巡检报告**：HTML
- **定时留痕**：日志

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
